Project 03 — PCG & MCP Pipeline
Dynamic Season PCG & Material Control System 안동 '만휴정' 계곡 배경 · Time, Season & Weather PCG System
Unreal Engine 5 · Claude & Codex MCP · Blender  |  제작기간 2026.07 – 2026.08 (개인 작업 100%)

안동 '만휴정' 계곡 배경을 바탕으로 실시간 계절 변화 시스템을 구축한 프로젝트입니다. 인게임 UI 슬라이더 및 머티리얼 파라미터 컬렉션(MPC)을 PCG 스캐터링 규칙과 연동하여, 에셋 재배치 없이 봄·여름·가을·겨울의 식생 및 적설량을 실시간으로 제어하고 메모리 부하를 방어했습니다.

UI 파라미터 제어

  • 위젯 UI 인터페이스와 PCG 파라미터를 연동으로 제어
  • 에셋 재배치 과정 없이 UI 슬라이더 조작만으로 사계절 연출

MPC 기반 조절

  • MPC를 활용해 지형 및 식생 최적화 조절
  • 개별 머티리얼 인스턴스 수정 없이 상태를 유지하며 실시간 색상 및 텍스처 변환

렌더링 최적화

  • 계절 변환 메모리 픽 현상을 방지
  • dynamic spawn 대신 HISM 인스턴싱 매핑하여 Mesh Draw Call 99% 절감
